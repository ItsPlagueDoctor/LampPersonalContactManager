# Lamp Personal Contact Manager

LAMP stands for Linux Apache MySQL Php and these four systems work together to run a website, where we have created a personal contacts manager. On this manager you can create contacts, edit contacts, and delete contacts.

As of September 29th, The website this project is running is available to see on https://plague.quest/
